# ZIP Folder Archiver

A simple Java application for creating ZIP archives and extracting files from them.

## Features

- Recursively archives directories and subdirectories.
- Preserves the original folder structure.
- Extracts files and recreates directories.
- Uses buffered byte streams for file processing.
- Automatically creates missing directories.

## Technologies

- Java
- Java I/O
- Java ZIP API
- Recursion
- Try-with-resources
- Exception handling

## Purpose

Created to practice file handling, byte streams, ZIP compression, and recursive directory traversal in Java.
